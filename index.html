How this works(可选：通过 JSON 远程更新状态)

默认从一个 status.json 拉取状态。你可以把它放在同一仓库的 /book-my-time/status.json，或放在一个 GitHub Gist Raw 链接，然后把地址填到下面的 STATUS_SOURCE。 

{
  "status": "free",            // free | busy | meeting | ooo | knock
  "message": "",
  "until": "2025-10-17T15:00:00-04:00",
  "office_hours": "Mon 14:00–16:00 @ ECE Building Room 3xx",
  "booking_url": "https://cal.com/your-id"  // 或其它预约链接
}

也支持用 URL 查询参数临时覆盖：?status=busy&msg=…&until=…（仅本地会话）。
